When a platform gets hacked, most developers spend hours figuring out which projects are affected. credmux turns that into a local-first drill: scan the machine, filter the impacted tokens, and jump straight to rotation. 플랫폼이 해킹됐을 때, 대부분의 개발자는 어떤 프로젝트가 영향받는지 파악하는 데 몇 시간을 씁니다. credmux는 그 과정을 로컬 중심 보안 드릴로 바꿉니다. 머신을 스캔하고, 영향받은 토큰만 추려서, 바로 교체로 연결합니다.

$go build -o credmux .
$DEMO_HOME=./demo ./credmux breach-drill vercel

No signup. No cloud dependency. Open source. Built for live demos and real agent workflows. 회원가입 없음. 클라우드 의존 없음. 오픈소스. 발표 데모와 실제 에이전트 워크플로우를 위해 만들었습니다.

How it works작동 방식

Three components. Two modes. One breach drill. 3개 컴포넌트. 2가지 모드. 침해 대응 드릴 한 번.

🛡️
SENTINEL
Breach Notifier

A platform gets hacked. Your Telegram bot tells you first. Tap a button. Run the drill. See impacted files and rotation steps without touching terminal UX if you do not want to.

플랫폼이 해킹됩니다. Telegram 봇이 먼저 알려줍니다. 버튼을 누르면 드릴이 실행됩니다. 터미널 없이도 영향 파일과 교체 단계를 확인할 수 있습니다.

🔍
VAULT
Discovery + Rotation

TruffleHog-backed scanning across your local machine. Finds token-shaped secrets in real files, filters by breached platform, masks the output, and points you at the right dashboard.

로컬 머신 전체를 TruffleHog 기반으로 스캔합니다. 실제 파일의 시크릿을 찾고, 침해 플랫폼 기준으로 추리고, 마스킹해서 보여준 뒤 올바른 교체 대시보드로 연결합니다.

🔐
GUARDIAN
Agent Isolation

Each project gets its own credential boundary. In cmux, credmux opens an isolated workspace, sets live sidebar state, and watches pane output for secret-shaped leaks.

프로젝트마다 자격증명 경계를 둡니다. cmux에서는 격리 워크스페이스를 열고, 사이드바 상태를 갱신하고, pane 출력에서 시크릿 형태를 실시간 감시합니다.

The positioning포지셔닝

Gitleaks

Strong at repository-focused secret detection. Not designed as a live breach workflow or agent isolation layer.

레포 중심 시크릿 탐지에 강합니다. 라이브 침해 워크플로우나 에이전트 격리 레이어로 설계된 도구는 아닙니다.

The scanning engine credmux builds on. Excellent detector coverage and verification. credmux wraps it with incident filtering, UX, and rotation flow.

Quick Reference

Everything you need to run the current demo build.

현재 데모 빌드를 실행하는 데 필요한 요약입니다.

Installation

# Prerequisite
brew install trufflehog

# Build the CLI
go build -o credmux .

# Demo setup
bash demo/setup.sh

# Run the breach drill
DEMO_HOME=./demo ./credmux breach-drill vercel

Commands명령어

credmux scan [path] Scan a directory with TruffleHog and mask results TruffleHog로 디렉토리 스캔 후 결과 마스킹
Defaults to DEMO_HOME, then HOME, then current directory.
credmux breach-drill [platform] Scan + filter by platform + guide rotation 스캔 → 플랫폼 필터 → 교체 안내
Current demo-safe platforms: vercel, github. JSON output is available for Telegram bot integration.
credmux workspace open [project] Isolate credentials per project 프로젝트별 자격증명 격리
Loads project tokens from Keychain. In cmux: creates workspace, sets sidebar status, and can activate the watcher.
python3 bot/bot.py Start Telegram breach notification bot Telegram 침해 알림 봇 시작
Requires TELEGRAM_BOT_TOKEN. Use /testbreach for the demo flow.
credmux profile create [name] Planned profile command 예정된 profile 명령
Stubbed in the current hackathon build. The page marks it as roadmap, not as shipping functionality.

Environment Variables환경변수

DEMO_HOME            Demo scan root override
CMUX_SOCKET_PATH     cmux socket path (default: /tmp/cmux.sock)
CMUX_SURFACE_ID      cmux pane surface id for watcher
CREDMUX_BINARY       Binary path used by the Telegram bot subprocess
